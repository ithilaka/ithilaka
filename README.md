## Portfolio Projects

### Excel

#### [Global Superstore Sales Performance Analysis](https://github.com/ithilaka/Excel-Reports/tree/main/Global%20Superstore)

- **Code:** [View Project](https://github.com/ithilaka/Excel-Reports/tree/main/Global%20Superstore)
- **Goal:** Analyze historical order data from a global retail/e-commerce business to identify key performance drivers across regions, products, and customer segments, track profitability and discount patterns, and enable data-driven decision-making.
- **Description:** Built an interactive Excel dashboard covering sales performance, profitability, discount patterns, shipping efficiency, customer segments, product categories, and regional performance, using Pivot Tables and Pivot Charts.
- **Skills:** Data cleaning, Pivot Tables, Pivot Charts, dashboard design, KPI reporting, sales/profitability/discount/regional/product analysis
- **Technology:** Microsoft Excel (Pivot Tables, Pivot Charts, Dashboards)
- **Results:**
  - Over 22% of orders had discounts greater than 20%, potentially impacting profit margins
  - ~30% of orders (7,541 orders) were loss-making, signaling a need to review pricing/discount strategy
  - Shipping cost accounts for 10.70% of total sales, highlighting a logistics optimization opportunity

### Python / Statistical Modeling

#### Electricity Demand Forecasting

[View Project](https://github.com/ithilaka/data-science/tree/main/electricity-demand-forecasting)

- **Goal:** Forecast daily electricity demand using historical consumption and weather data.
- **Analysis:** Data cleaning, exploratory data analysis, seasonal analysis, feature engineering, and residual analysis.
- **Models:** 1-Day Naive, 7-Day Seasonal Naive, Multiple Linear Regression
- **Features:** Temperature, precipitation, weekend indicator, 1-day lag, and 7-day lag
- **Model Evaluation:** MAE, RMSE, WAPE, and Forecast Bias
- **Tools:** Python, Pandas, Matplotlib, Statsmodels, Scikit-learn, Jupyter Notebook
